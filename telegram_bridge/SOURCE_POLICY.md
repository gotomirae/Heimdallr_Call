# Kairos 필수 출처와 엄격한 최신성 정책

<!-- PRD Ref: §8.7 -->

2026-10-04 사용자 변경 지시. 기업·산업 요청 및 기존 working 요청 재개 모두에 적용한다.
설치된 Kairos 스킬과 종전 문서의 '오래된 이전 분석은 변화 비교용 허용', '웹 구자료는 배경용 허용' 예외를 이 프로젝트에서는 폐지한다.
분석 실행일 Asia/Seoul 기준 최근 달력상 3개월부터 실행일까지 발행·유효하게 갱신된 자료만 사용한다. 오늘 날짜를 영구 고정하지 않는다.

## 반드시 조회할 Notion 자료

기존 SnowBall Heritage·기업 분석·산업 분석 루트와 완료된 이전 분석 조회를 유지하면서, 아래 두 루트의 관련 산업·기업 본문을 **두 요청 유형 모두** 반드시 조회한다.

- 산업·기업 모니터링: https://app.notion.com/p/2_1-36a9c770aa61809c95e5c1117f9779b5
- 추가 산업·기업 자료: https://app.notion.com/p/3999c770aa6180ecb514e74eb998e127?v=3999c770aa6180cf8f5f000c1e3b0c7b

연결 페이지·하위 페이지와 데이터베이스의 관련 행 본문을 읽고 목록은 페이지네이션으로 끝까지 확인한다. 두 번째 링크의 v는 뷰 ID이며 문서 발행일이나 원문 ID로 취급하지 않는다. 이름뿐 아니라 종목 코드·시장과 산업 범위를 대조한다. 현재 실행 페이지·작성 중·실패 분석은 근거에서 제외한다.

이전 완성 분석도 최근 3개월인 경우에만 비교·반영하고 원본 링크를 남긴다. 3개월 이전 완성본은 역사 비교용으로도 사용하지 않는다. 기간 내 완성본이 없으면 '최근 3개월 비교 가능한 이전 분석 없음'으로 표시한다.

## 반드시 조회할 웹사이트 자료

- Hermes Call: https://hermes-call-psi.vercel.app/
- Heimdallr Call: https://heimdallr-call.vercel.app/
- SAGE: https://sage-gotomiraes-projects.vercel.app/

기업·산업 모두 세 사이트의 해당 기업·산업 페이지, 관련 분석·자료를 찾아 실제 본문을 읽는다. 홈페이지 링크나 검색 요약만으로 반영 완료라 하지 않는다. 회사 식별·섹터 범위를 대조하고 직접 상세 URL, 자료일, 관점·수치 및 이번 판단에 반영한 내용을 기록한다.
동일 원문의 재배포나 세 사이트의 동일 DB 수치를 독립적인 세 가지 검증으로 세지 않는다. 사이트의 해석·점수는 보조 판단이며 핵심 실적·수주·점유율은 공시·IR·공식 통계 원문으로 교차 검증한다. 로그인이나 유료 생성이 필요하면 접근 한계를 기록하며 유료 분석·주문·Telegram 인증을 임의 실행하지 않는다. 다른 프로젝트의 DB나 자료를 변경하지 않는다.

## 모든 활용자료의 날짜 기준

- Drive·Notion·세 웹사이트·공시·IR·뉴스·증권사 리포트·블로그·Telegram 및 이전 분석 모두 3개월 상한을 적용한다. SungwooInsight는 더 엄격한 기존 72시간 기준을 유지한다.
- 명시적 발행일·분석일·정정일 또는 실제 내용 갱신일을 확인한다. 파일/폴더 수정일, 페이지 접속일, 사이트 배포일, 기사 재전송일만으로 최신성을 인정하지 않는다. 페이지가 오늘 갱신되어도 포함된 오래된 첨부를 새 자료로 취급하지 않는다.
- 자료일 미확인·미래일·3개월 초과 자료는 분석 근거에서 제외한다. 최근 문서에 있는 과거 분기 수치는 최신 문서가 해당 기간·수치를 실제 제공하는 경우 출처와 회계기간을 명시해 추이 분석에 사용할 수 있다. 오래된 원문 자체를 새 출처로 세지는 않는다.
- 산업 Drive의 가장 최근 날짜 하위 폴더 하나, 기업 Drive의 최근 3개월 발행본 전체 규칙을 유지한다. 해당 범위가 비어도 오래된 자료로 자동 대체하지 않는다.

## 실행 장부와 보고서 검증

필수 다섯 루트 각각에 `조회 시각(KST) | 대상·검색어 | 관련 상세 원문 URL | 발행/갱신일 | 포함/제외 이유 | 본문 열람 범위 | 반영 내용 | 교차 검증 원문`을 기록한다. 기존 Drive·Notion·공식 웹·Telegram 출처 장부도 유지한다.
조회 성공·관련 자료 없음·기간 초과·자료일 미확인·접근 실패를 구분한다. 접근 실패 자료는 '⚠️ 직접 확인 필요'와 링크·실패 범위를 보고서에 남기고 사실 근거로 사용하지 않는다. 관련 자료가 없을 때 무관한 내용을 억지로 반영하지 않는다.
보고서 발행 전 다섯 루트의 조회 결과와 모든 사용 출처의 3개월 적합성을 확인한다. 필수 출처를 읽지 못했다면 공개 원문으로 분석을 이어갈 수 있지만 '모든 필수 자료 반영 완료'라고 표시하지 않고 누락·한계를 명확히 밝힌다. 중요한 주장에는 해당 내용의 원문 위치 링크를 붙인다.
