# 2026-09-11 — 기업 투자 매력도·QoQ 운영 반영

## 완료한 것

- 발굴 목록의 매출·영업이익 QoQ가 DB에 있어도 보이지 않던 원인을 대시보드 SELECT 누락으로
  확인했다. `revenue_qoq`·`op_qoq`를 조회 계약에 추가하고 숫자 렌더를 복구했다.
- 섹터 셀의 ETF 테마·분류 근거 상세 문구를 제거하고 섹터명만 표시했다.
- 기존 실적 A~D 원점수는 감사용으로 보존하면서 대표 기업 점수를 산업 성장 10, 산업 내 위치 10,

# 2026-09-11 — 반도체 4분류·현재 추천 정렬 완성

## 완료한 것

- 반도체를 **IDM·소재·부품·장비** 네 분류로 고정하고 업종명·주요제품·사업설명의
  반도체 맥락과 구체 제품 증거를 함께 판정하도록 Python/대시보드 분류기를 동기화했다.
  개별 종목 하드코딩 없이 소재·부품처럼 더 구체적인 증거가 일반 장비 문구보다 우선한다.
- `기업 매력도`를 전 화면에서 `투자 매력도`로, 정렬 상태의 `원본`을 `기본`으로 통일했다.
- 발굴 표의 섹터·관심·종목명·등급·분기 5개 열을 합계 **386px**로 줄이고 가로 스크롤에도
  고정했다. 브라우저에서 `scrollLeft=1,053px`일 때 다섯 열의 왼쪽 위치가
  **223·335·379·491·539px**로 유지되는 것을 확인했다.
- 기본 정렬을 최신 분기 → 등급 → 현재 유망 섹터 → 투자 매력도 → 낮은 PRI → 영업이익 YoY
  순의 사전식 비교로 바꿨다. 점수·PRI·뉴스를 하나의 합산 숫자로 만들지 않아 ADR 5를 지켰다.

  점수화하지 않고, 금리·산업·지정학 문맥은 사용자가 확인할 가드레일로만 제공한다.
