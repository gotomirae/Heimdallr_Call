## 발굴 목록 항목별 정렬 순환

- 사용자 지정에 따라 모든 정렬 항목의 클릭 순서를 **기본 → 오름차순 → 내림차순 → 기본**으로
  통일했다.
- 새 항목은 기존 다중 정렬 체인의 끝에 오름차순으로 추가한다. 같은 항목을 다시 누르면 그 자리에서
  내림차순으로 바뀌고, 한 번 더 누르면 해당 규칙만 제거된다. 먼저 설정한 다른 항목의 우선순위와
  방향은 유지한다.
- 정렬 버튼의 접근성 이름에 현재 상태·우선순위와 다음 상태를 함께 표시한다.

### 검증

- 실제 브라우저에서 투자 매력도가 `기본 → 오름(1순위) → 내림(1순위) → 기본`으로 순환하는 것을
  확인했다.
- 투자 매력도 오름 뒤 주가 반영도 오름을 추가해 각각 1·2순위가 되는지 확인했다. 투자 매력도를
  내림으로 바꿔도 주가 반영도 2순위는 유지됐고, 투자 매력도를 기본으로 돌리자 주가 반영도만 남아
  1순위가 됐다.
- 전체 오프라인 **852 passed·1 skipped·3 needs_network deselected**, Dashboard production build
