# 2026-08-30 — LLM 사실 숫자 참조 경계

## 목표

실제 Provider 4-case가 모두 입력 숫자의 단위 환산·새 계산 때문에 저장 차단된 문제를,
프롬프트 반복이 아니라 구조적으로 줄인다. 실제 유료 호출과 운영 쓰기는 사용자 승인 전
실행하지 않는다.

## 한 일

- `src/analysis/numeric_grounding.py`
  - 입력의 단위 있는 사실 숫자와 분기 파이프 표 숫자를 인라인 참조로 변환한다.
    예: `+595.1억원` → `[[F001:+595.1억원]]`.
  - 새 요청의 사실 서술은 전체 표식 또는 `[[F001]]` 참조를 저장 전 정확한 원문 표시값으로 복원한다.
  - 입력에 없는 참조와 값이 바뀐 전체 표식은 실패한다. 직접 쓴 숫자는 기존 동일 단위 gate가 검사한다.
  - 미래 시나리오·risk watch metric은 투자 판단 숫자라 참조 계약에서 제외한다.
  - 참조 없는 과거 request snapshot은 그대로 처리해 exact replay를 소급 변경하지 않는다(T111).
- `src/analysis/analyze.py`
  - 최초에는 모든 새 Canonical request에 참조 계약을 적용했다.
  - 참조 복원 뒤 기존 동일 단위 grounding gate를 다시 적용한다.
- `src/analysis/prompts.py`
  - 시스템 프롬프트와 schema description이 숫자 직접 복사를 요구하지 않고 `[[F...]]`를
    반환하도록 통일했다. 기존 화면·payload 스키마는 바꾸지 않았다.
- 회귀 테스트 7건을 추가하고 canary mock도 새 계약을 따르게 했다.
- ADR 10과 PRD §7을 갱신했다.
