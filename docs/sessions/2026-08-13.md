**Windows에서 stdout을 파이프로 넘기면 등급 기호(★ ○ △ ·)와 표 괘선(═)에서 죽는다.**

(실측 확인). 이 프로젝트는 매트릭스 등급을 상시 출력하므로 **모든 CLI에서 재발한다.**
GitHub Actions 로그 캡처도 파이프다.

→ `src/utils/console.py`의 `enable_utf8_stdout()`을 엔트리포인트 첫 줄에서 호출.
**이후 Phase에서 출력하는 스크립트를 새로 만들 때마다 이 호출을 넣을 것.**

## ★ setWebhook 방어선

봇(@Invest_EarningCallBot)을 HermesCall과 공유한다. `setWebhook`은 이전 웹훅을
**에러 없이 덮어쓰므로**, 호출하는 순간 HermesCall의 `/add /list /cost /status`가 조용히 죽는다.

KIS 주문 API와 같은 방식으로 **클라이언트 안에서** 막았다:

```
ALLOWED_METHODS = {"sendMessage", "getMe"}

```
