# 2026-08-28 — LLM Provider offline replay 평가 기반

## 목표

유료 canary 전에 같은 `AnalysisInput`에서 저장된 Anthropic/OpenAI payload를 외부 호출 없이
동일 기준으로 비교하고, synthetic 결과를 실제 Provider 우열로 오인하지 않게 한다.

## 한 일

- `src/analysis/evaluation.py`에 순수 offline evaluator를 추가했다.
  - JSON Schema를 `$defs`까지 재귀 검증한다.
  - 사실 서술 영역의 숫자가 입력에 존재하는지 단위와 함께 대조한다.
  - JSON 블록의 `rel_ret_3m` 같은 값은 필드 의미를 복원해 `%p` 인용을 정상 처리한다.
  - replay별 핵심 근거 anchor 커버리지를 측정한다.
  - 트리거 날짜가 기준일 이후이며 3/6개월 창 안인지 확인한다.
  - event와 verifiable metric이 숫자·공시·운영지표로 검증 가능한지 확인한다.
- `src.analysis.eval_run` CLI를 추가했다. 파일만 읽고 JSON 보고서를 출력하며 API·DB를 쓰지 않는다.
- 합성 턴어라운드 replay fixture를 추가했다. `synthetic=true`라 승자를 선언하지 않는다.
- 비교 가능한 suite는 모든 사례에 같은 Provider가 정확히 한 번씩 있어야 한다(T105).
- 평가 배점·통과선·canary 하드캡을 `constants.py` 한 곳에 두고 PRD §7.4와 대조한다.
- 사용법과 실제 비교 성립 조건을 `docs/evals/README.md`에 기록했다.
