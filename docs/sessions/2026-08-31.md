## 목표

종목 상세의 주가·밸류에이션 근거를 실제 Source와 거래일 기준으로 명확히 하고,
잠정실적 분석이 정기보고서 확정치 도착 뒤 자동으로 갱신되게 한다.

## 구현

- 네이버 일봉을 ISO 주별 마지막 실제 거래일로 접어 `weekly_prices`에 저장하고 상세 차트에 연결했다.
- 네이버 기업실적분석의 최근 확정 PER과 가장 가까운 연간 (E) PER을 컨센서스 스냅샷에 보존한다.
  화면과 LLM은 Source를 명시하며 이 값을 우선하고, 내부 최근 4분기 계산값은 검산으로 남긴다.
- PRI 카드에 P1~P4 원입력·구간·분모를 표시한다.
- DART 확정 재무 저장 시 잠정치 대비 절대 차이와 양수 구간의 증감률을 보존한다.
  분석 payload에 `preliminary|final` 단계를 기록하고, 새 확정치가 들어온 같은 분기만 갱신한다.
- 정기보고서 발췌의 중복 키를 종목 단위에서 종목·연·분기로 고쳐 새 분기 근거를 받을 수 있게 했다.
- 시즌 폴링과 수동 분기 백필에 확정 재무→파생지표→스크리너→발췌→확정 분석 순서를 연결했다.
- 마이그레이션 검사가 연결 실패를 스키마 부재로 오판하지 않도록 3상태 판정으로 고쳤다(T130).
