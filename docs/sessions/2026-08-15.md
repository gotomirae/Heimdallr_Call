### 3. ★ PRI 분모 하한 — 이번 세션에서 가장 위험했던 것 (T35)

PRI를 배선하고 처음 돌렸을 때:

```
PRI 측정 1103/1103종목 · 중앙값 25.6
정규화 분모 분포: {25: 1103}
등급: {'·': 197, None: 765, '○': 88, '★': 27, '✕': 17, '△': 9}
발송 대상(★/○) 115종목
```

**분모가 전부 25다.** `rel_ret_3m`이 아직 한 종목도 수집되지 않아 P2(52주 위치, 25점)
하나만으로 PRI가 나온 것이다. "3개월간 시장 대비 얼마나 안 올랐나"를 **전혀 모르는 채로**
미반영을 선언했고, ★ 27종목 · ○ 88종목이 배정됐다.

52주 저점 부근이기만 하면 이미 시장을 크게 이긴 종목도 ★가 된다 —
이 시스템이 피하려는 바로 그 오류(**좋은 기업 ≠ 좋은 투자**)를 정면으로 저지른다.
에러도 경고도 없고, 등급표는 그럴듯하게 채워진다.

스코어(A~D)는 축이 4개라 하나가 빠져도 나머지로 판정이 서지만,
**PRI는 P1 하나가 40%를 쥐고 있어 축 단위 정규화만으로는 못 막는다.**

→ `PRI_MIN_DENOMINATOR = 40`. 미만이면 `pri = None`(0점 아님).
  P1 단독(40) 또는 P2+P4(40) 이상이 모여야 판정한다.

적용 직후(시세 수집 전)에는 시세가 있는 3종목만 판정됐다 — **이게 맞는 그림이다.**


### 4. PER/PBR 교정 — 사용자가 지적한 것

KIS가 주는 `per`은 **과거 12개월 EPS 기준(후행)**이다. 실적이 급가속하면 분모가 옛날
이익이라 크게 과대평가되는데, **이 시스템이 겨냥하는 구간이 정확히 그 왜곡이 가장 큰
구간이다.** 후행 PER만 보여주면 "이미 반영됐다"는 **정반대 결론**으로 읽힌다.

삼성전자 실측:

| 구분 | 값 |
|---|---|
| KIS 후행 PER | **41.8배** |
| 최근 4분기 순이익 기준 PER | **10.6배** |
| 괴리 | **3.9배 과대** |

→ `ttm_net_income()`으로 4분기 누적 순이익을 직접 만들어 PER을 재계산하고,
  후행과 나란히 보여준 뒤 1.5배 이상 벌어지면 경고를 붙인다.
  **4개 분기가 다 모이지 않으면 추정하지 않고 None**을 준다(연율화 금지).

### 9. ★ 흑전 서프라이즈가 0점으로 뒤집히는 문제

부호 전환 3건이 걸렸다. 그중 **삼성SDI 2026.2Q — 컨센서스는 적자(−356억)를
예상했는데 실제는 흑자(+2,038억)** 였다. 가능한 최강의 서프라이즈다.

두 경로 모두 틀린다:

| 처리 | 결과 |
|---|---|
| %를 계산한다 | `(2038−(−356))/(−356)` = **−672%** → `_tiered`가 기준 미달로 읽어 **0점** |
| %를 막고 None을 준다(T25) | c1이 **미측정** → C축 안에서 9점 조용한 감점(T26) |

**게이트가 흑전을 G2 통과로 처리하는 선례**가 이미 있으므로 같은 규칙을 적용했다 —
새 정책이 아니라 기존 설계의 일관된 적용이다.

- `흑전 서프라이즈` → c1 만점 9점 (실측: 삼성SDI 9.0 확인)
- `적자 쇼크`(흑자 예상 → 적자) → 0점. 미측정이 아니라 명백한 0이다.
- `적자 예상 부합`(둘 다 적자) → None. 적자 폭 개선을 흑자 전환과 같은 급으로 볼 수 없다.

### 10. 0점 항목이 메시지에서 사라지던 문제

`score_breakdown()`이 `value > 0`인 항목만 보여줘, **측정해서 0점인 것과 미측정이
구분되지 않았다.** 삼성전자 C 3/15에서 매출 서프라이즈 0/6(컨센서스 하회)이 통째로
안 보였고, 왜 축 점수가 낮은지 읽을 수 없었다.

```

```

### 11. ★ 매출이 통째로 결측이던 29종목 복구 (T39)

앞 절에서 "유니버스 1,322 vs 스크리너 대상 1,103 → 219종목 누락"이라 적었는데
**그 수치가 틀렸다.** 219는 업종 제외(210)와 혼동한 것이다. 실제 내역:

| 구분 | 종목 수 |
|---|---|
| 업종 제외(은행·보험 등, 의도된 것) | 210 |
| 재무 자체가 없음 | **1** (퀄리타스반도체 — 2023-10 상장) |
| 재무는 있으나 **전 분기 매출 결측** | **8** |

그 8종목을 파고들었더니 `fnlttMultiAcnt`(주요계정)가 **매출 계정을 아예 반환하지 않는**
회사들이었다. 응답은 status 000이고 행 수도 정상인데 손익 계정이
`영업이익 · 법인세차감전순이익 · 당기순이익 · 총포괄손익`뿐이다.

**영업이익·순이익은 멀쩡히 온다.** 그래서 수집이 성공한 것처럼 보이고 매출만 None이 되어,
게이트가 조용히 판정 불가로 빠졌다. 한국경제TV·폴라리스오피스처럼 매출이 분명히 있는
회사들이 발굴 대상에서 사라져 있었고, **어떤 카운터에도 잡히지 않았다.**

전체 피해는 8종목이 아니라 **29종목 166행**이었다(일부 분기만 결측인 21종목 포함).

→ `영업이익은 있는데 매출이 없는` 조합일 때만 `fnlttSinglAcntAll.json`으로 폴백.
  거기엔 **`영업수익`** 으로 들어 있다.

**폴백을 붙이고도 한 번 실패했다** — 단일회사 응답에는 `fs_div` 필드가 없어
(요청 파라미터라서) 필터가 전 행을 걸러냈다. 에러 없이 "폴백했는데 못 찾았다"로 보였고,
2종목 20행이 전부 매출 None으로 남았다. `setdefault`로 주입해 해결.

손계산 대조(한국경제TV 2025):

```

합계 75,910,005,501  =  DART 연간 75,910,005,501   차이 0 ✓
```

복구 결과:

```

전 분기 결측 종목   8 → 0
스크리너 대상   1,103 → 1,111

```

남은 9행은 이노스페이스(2024년 발사체 개발 단계)·큐라클처럼 **실제로 매출이 없던 구간**이라
수집 실패가 아니다.

### 12. `screen_results` 빈티지 정합성 (T40)

최종 점검에서 **등급 부여 수 ≠ 게이트 통과 수**가 나왔다:

```
총 1,601행 · 게이트 통과 511 · 등급 부여 344   ← 안 맞는다
```

PK가 `(code, fiscal_year, fiscal_quarter)`라 종목당 여러 행이 남는다는 걸
전체 집계에서 놓친 것이다. 원인 둘:

1. **미래 분기 잔재** — T36 가드 이전에 들어온 `2026.3Q` 행.
2. **구 로직 이력** — 2026.1Q 행 1,111개가 **PRI·C축 배선 이전**에 저장돼
   게이트 통과 312 중 등급이 145개뿐이었다. 값이 틀린 게 아니라 계산 시점이 다르다.

→ `_save()`가 평가 분기보다 **미래**인 행만 지운다(과거는 이력으로 남긴다).
→ `--quarter 2026.1 --save`로 그 분기를 현재 로직으로 다시 만들었다.

**여기서 되돌릴 수 없는 함정을 하나 만들 뻔했다.** 고정 분기 모드에서 미래 분기 정리를
그대로 돌리면 전 종목의 평가 분기가 2026.1Q가 되어 **정상적인 2026.2Q 행 481개가 통째로
삭제된다.** 삭제 카운터만 보면 "정리했다"로 읽힌다 → 고정 모드에서는 정리를 건너뛴다.

## 막힌 것 / 미완

1. **D축은 미측정.** 현금흐름·주식수는 정기보고서에서 오는데 잠정 구간에는 없다.
   분모 82가 최대이고, 확정 재무가 들어와야 100이 된다.
2. **컨센서스는 2026.2Q 207종목뿐이다.** 2026.1Q로 평가되는 종목은 C축이 없다
   (수집을 안 한 분기다). 분모 67이 여전히 다수(272/344)인 이유다.
3. **PRI P3(3년 PER 밴드)**는 `per_pctile_3y`가 비어 있어 미측정 → 분모가 65에 머문다.
   일봉 축적이 필요하다.
4. **PRI P4(발표 D+1 반응)**는 P11(성과 추적)에서 배선한다.
5. **상위 포화는 줄었지만 남아 있다.** 만점 7 → 5종목. 컨센서스가 없는 소형주가
   상위를 차지하는 구조는 그대로이고, **그건 의도한 바다**(ADR 1·2).

## 다음 세션이 알아야 할 것

1. **매출 결측은 §11에서 해결했다.** 남은 것은 퀄리타스반도체(432720) 1종목 —
   2023-10 상장이라 `quarterly_fundamentals`에 행 자체가 없다. 왜 없는지 미확인.
2. **컨센서스를 2026.1Q까지 확장하면** C축 커버리지가 72 → 200종목대로 늘어난다.
   단 **컨센서스 없는 종목이 불리해지면 안 된다**(ADR 2) — SC6를 매번 확인할 것.
3. **P9 대시보드는 아직 프로젝트가 없다.** `dashboard/`에 route.ts 하나뿐이다.
4. 미래 분기 행(042520)은 **잘라내고 있을 뿐 고치지 않았다.** 비12월 결산 기업의
   분기 매핑이 맞는지는 별도 확인이 필요하다.
5. **시세는 1일 1회 갱신이 전제다**(T23). PRI가 시세에 직접 걸리므로,
   장중에 돌리면 등급이 실행마다 바뀐다.
