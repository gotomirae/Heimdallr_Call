### T41 `"use client"` 경계를 넘는 non-component export

`toChartPoints`를 차트 컴포넌트 파일에 두고 서버 컴포넌트에서 import했다.
**`npm run build`도 `tsc --noEmit`도 통과한다.** 그런데 페이지를 열면 500:

```
TypeError: (0 , ...QuarterlyChart...toChartPoints) is not a function
```

클라이언트 경계를 넘을 수 있는 건 컴포넌트뿐이다. → `lib/chart.ts`로 분리.
**PRD §9가 "브라우저로 실제 확인"을 검증 조건으로 못박은 이유를 그대로 겪었다.**

### T42 Recharts 검증에서 두 번 오진

**① 애니메이션이 첫 프레임에 멈춤** — `stroke-dasharray: "0px, 807px"`, 막대 0개.
패널 비표시로 rAF가 안 도는 탓인데, **백그라운드 탭에서도 같은 일이 난다.**
→ `isAnimationActive={false}`. 데이터 대시보드에 진입 애니메이션은 얻는 게 없다.

**② `ReferenceArea`를 `rect`로 찾다가 "안 그려졌다"고 오진** — Recharts 3.x는 `path`로 렌더한다.
셀렉터가 틀렸을 뿐인데 **있지도 않은 원인(선언 순서)을 고치고 주석까지 틀리게 썼다.**
실제로는 처음부터 3개가 정확한 좌표에 있었다. 주석을 정정했다.

**③ 사분면 라벨은 SVG 안에서 렌더되지 않는다** — prop도 `<Label>` 자식도 text 0개.
→ HTML 범례로 뺐다. 렌더가 보장되고 폭이 좁을 때 겹치지도 않는다.

## 설계 판단

- **미측정과 0점을 끝까지 구분한다.** 축 미측정은 "분모에서 제외(0점이 아니다)"를 문장으로
  쓰고, 축 안의 결측은 `↳ 미측정(-N)`으로 따로 표시한다(T26). 측정해서 0점인 항목은
  `0/N`으로 보인다(T38).
- **PRI가 null인데 측정 항목이 있으면 이유를 쓴다.** "분모 N점으로 부족해 판정 보류" —
  숨기면 "반영도 0"과 구분되지 않는다(T35).
- **매트릭스는 두 축이 다 있는 점만 찍는다.** 하나를 0으로 채우면 원점 근처에
  가짜 군집이 생겨 사분면 판독이 통째로 틀린다.
- **컨센서스 없음을 변명하지 않는다.** "커버리지 없음"과 함께 코스닥 60%가 리포트 0건이며
  이 시스템이 그 구간을 노린다는 사실을 화면에 쓴다(ADR 1·2).
- 등급 없음은 "판정 불가"로 쓴다. "낮다"가 아니다.
