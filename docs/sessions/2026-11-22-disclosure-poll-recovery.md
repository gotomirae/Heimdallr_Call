# 공시 수집 중단 복구 (2026-11-22)

PRD §5.1·§10, ADR50, T298.

- 운영 공시 실행 최근 40건 중 20건 취소, 1건 실패, 18건 성공, 1건 진행 중이었다. 성공에는 이미 완료된 슬롯의 중복 실행도 있다.
- 02시 실행 44927593159는 OpenDART 공시 목록 연결 제한 5회 이후 실패했다. 12시 실행 44978580804는 공시 751행, 확정재무 5행, 파생지표 12,399행과 선별 1,223행을 저장했지만 15분 한도에서 즉시 알림이 취소돼 완료 표식이 생략됐다.
- 14시 실행 44987445814는 10분 31초 만에 공시 751행, 선별 1,223행, 발췌 4건과 완료 표식까지 처리했다. 11월 20일 16시 일일 지표는 1,227종목 갱신, 부분 확보 1종목, 실패 0으로 완료했다. 운영 대시보드 홈과 SK하이닉스 상세는 HTTP 200을 반환했고, Telegram 접수와 Pro 큐 확인은 최근 상태 기록에서 정상 작동했다.
- 같은 날짜 범위의 공시 목록을 한 번만 조회해 공시장부와 잠정실적 반영에 공동 사용한다. 날짜 범위는 KST로 산출하며 작업 제한을 30분으로 조정했다. DART 목록 오류 응답은 작업을 실패시키고 완료 표식을 남기지 않는다. 기존 시즌 2시간 예약을 사용한다.
- 11월 15~22일 읽기 전용 실제 재생에서 DART 34회, 전체 3,346건, 분류 751건(잠정 4·정기 686·계약 61), 규칙 밖 이름 0종을 확인했다. 동일 목록 재조회 제거로 이 구간의 목록 호출은 68회에서 34회가 된다. 오프라인 전체 회귀 1,446 통과, 36 건너뜀, 3 제외.
- 18시 실행도 15분에 발췌에서 취소됐다. 14시 실행의 알림 실패 2건은 원익QnC와 TYM의 확정·잠정 차이 객체를 숫자로 포매팅한 예외였다. 저장값의 금액·선택적 변화율과 기존 숫자형을 모두 렌더링하고 종목별 문맥 조회의 DB 페이징에 종목·분기 조건을 적용했다. T299.
- 운영 DB 원익QnC·TYM 2026Q3으로 발송 없이 렌더링 2/2 성공. 영업이익 차이는 각각 -68,072원·-293,228원이고, 조회·렌더링 소요는 각각 2.56초·0.64초였다.
