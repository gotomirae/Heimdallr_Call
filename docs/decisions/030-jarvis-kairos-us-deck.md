# ADR 30. JARVIS Kairos 요청·미국 종목·Drive 준비·별도 발표자료

- 상태: 채택 (2026-10-05, 사용자 G절·D59)
- PRD: §8.7 G
- 이전 결정: ADR 19·20·21·22

## 결정

1. Vault 토큰으로 인증된 JARVIS 버튼 요청도 Kairos 실행 조건이다.
   source/시장/대상 식별자를 큐에 보존하고 JARVIS 요청은 음수 ID와 chat/user 0을 사용한다.
   Telegram 개인 채팅 인증은 유지한다. JARVIS 요청에서 Heimdallr 메시지를 보내지 않는다.
2. 미국 기업은 SEC 명부로 확인한 ticker와 market=US를 사용하며 국내 code FK는 NULL이다.
   국내 스크리닝·매매·유니버스 계약에는 미국 티커를 섞지 않는다.
3. 기업 재사용은 30일 이내이고 이후 실적 발표가 없을 때만 허용한다.
   산업은 같은 매핑 폴더의 30일 완료본을 재사용한다.
   중복·6건 보호·deck claim은 DB 트랜잭션과 인덱스로 직렬화한다.
4. 사용자 YAML 명시 매핑·정규화를 Telegram에도 우선 적용한다.
   JARVIS 미매핑 비어 있지 않은 산업은 다음 번호 폴더를 자동 생성하며 awaiting_input을 금지한다.
   이 범위에서는 ADR 21의 Telegram 폴더 확인을 대체한다.
5. Drive 준비는 claim 후 LLM 없이 수행한다. 최근 3개월 자료가 있으면 재사용한다.
   새 기업 자료는 공식 DART/SEC 원문을 받고 실제 파일 형식을 검증한다.
   다운로드 실패·IR 부재는 장부에 남기고 분석을 막지 않는다.
6. PPT는 완료된 기업 분석의 별도 🎤 요청에서만 생성한다.
   기존 kairos-deck 스킬을 Claude 구독 로그인으로 창 없이 실행하고 API 과금 변수를 제거한다.
   사용량 한도는 30분 뒤 재시도, 4번째 한도 실패는 종료한다.
   불확실한 실행·프로세스 트리 종료는 자동 재생하지 않아 중복 첨부를 막는다.
7. JARVIS 분석 완료 전에는 실제 Notion connector 재조회 증빙을 저장·검증한다.
   실전 검증은 실제 사용자 요청만 사용하며 시험용 Notion 페이지를 만들지 않는다.

## 적용 한계

운영은 SQL·SEC_USER_AGENT·Claude 구독 로그인·Drive·PowerPoint·1분 작업 설치가 필요하다.
이 세션은 운영 요청이나 Notion 페이지를 만들지 않았으며 실제 버튼 종단 검증은 설치 후 수행한다.
