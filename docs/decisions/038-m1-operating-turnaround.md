# ADR 38: JARVIS M1 실적 조건에 영업이익 턴어라운드 경로를 더한다

상태: 채택 · 2026-10-08 · PRD §8.8 · JARVIS D68 · INTEGRATION_TASKS L-1

**무엇을**: `entry_checks` M1 재무 = **증가·가속(기존 조건 전부)** 또는 **영업이익 턴어라운드**(최근 분기 영업이익 > 0 ∧ 전년 동기 영업이익 ≤ 0 — 라벨 '흑전' 또는 4분기 전 영업이익 부호 ∧ 매출 YoY > 0). `m1_detail` 에 `earnings_path`(`growth_accel` 우선 · `turnaround` · null) · `growth_pass` · `turnaround_pass` · `turnaround_checks` 를 남긴다. 적자축소는 아직 적자라 제외한다. 기저효과 경고·연간 컨센서스는 증가·가속 경로에만 적용한다(흑전은 적자 기저라 기저효과 판정이 뜻이 없다). 상수 `ENTRY_M1_TURNAROUND_*` 는 JARVIS `rules.yaml > entry_core.M1_earnings_up_price_not.turnaround` 와 같은 값이며 T216 대조 테스트에 포함했다.

**왜**: 사용자가 발굴하려는 종목은 "실적 증가·가속 종목 **또는** 영업이익 턴어라운드(매출 증가) 종목"이다(2026-10-08). 게이트 G2 는 이미 흑전을 가속의 가장 강한 형태로 통과시키지만, M1 은 부호 전환 구간을 탈락시켜 흑전 종목이 1단계에서 조용히 사라졌다. 10/8 실측(읽기 전용): 1단계 재무 통과 194 = 증가·가속 101 + 턴어라운드 93, PRI<50 까지 72 + 24.

**되돌리면 무엇이 무너지는가**: JARVIS 🎯 F축은 턴어라운드를 인정하는데 🟢 M1 은 인정하지 않아 같은 종목이 🎯 에는 오르고 🟢·🟡 에는 구조적으로 못 오른다. 판정 위치(M1=원 프로젝트, D13)도 그대로라 JARVIS 가 대신 계산할 수 없다(1단계 탈락 종목은 수급·일봉을 아예 보지 않는다).
