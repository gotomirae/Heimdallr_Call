# ADR046 · 명시 수주일자가 보고기말 뒤인 계약표의 분기 사용 차단

보고서 제목의 분기만으로 모든 수주표를 그 분기 말 수치로 간주할 수 없다. 명시 수주일자/계약일자 열에 보고기말 이후 실제 날짜가 있으면 해당 표를 분기 잔고·QoQ에 사용하지 않는다. 미래 납기일은 이 조건과 다르다. 새 날짜와 단위로 임의 역산하지 않는다.

파서v12는 해당 표만 제외하고 정상 다른 범위/공식 IR는 보존한다. 기간 충돌의 보고기말·수주일자·이유를 구조화 장부와 화면에 별도 표시한다. 검증된 다른 수치가 있더라도 경고를 지우지 않는다. 추가 자료가 없으면 해당 분기 결측은 유지한다.
