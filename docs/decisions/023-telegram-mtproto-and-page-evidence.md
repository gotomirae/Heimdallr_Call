# ADR 23 — Telegram 원소스는 읽기 전용 MTProto, 문서 근거는 비파괴 페이지 표시

## 상태

승인 · 2026-09-27

## 맥락

Kairos가 SungwooInsight·DOC_POOL·sunstudy1234를 웹 미리보기로만 확인하면 게시물 본문과
첨부 리포트를 안정적으로 읽을 수 없다. Bot API는 새 update 수신용이며 과거 채널 이력을
검색하는 계약이 아니다. 또한 보고서 링크가 PDF 파일 첫 화면만 열면 중요한 수치가 있는
페이지를 사용자가 다시 찾아야 하고, 원본 파일에 직접 강조를 쓰면 자료 보존성이 깨진다.

## 결정

1. 세 채널은 사용자가 직접 승인한 Telethon MTProto 사용자 세션으로 읽기 전용 조회한다.
2. 세션·API hash는 로컬 비밀로 보존하고 수집기는 게시·전송·반응 기능을 제공하지 않는다.
3. SungwooInsight는 직전 72시간 전체, DOC_POOL·sunstudy1234는 최근 3개월을 정식 대상명과
   검증된 별칭으로 날짜 경계까지 검색한다.
4. 출처 장부는 개별 게시물 ID 영구링크·본문·첨부 파일과 채널별 상태를 기록한다.
5. PDF 근거는 페이지·절/표·짧은 근거 문구를 저장한다. 검증된 뷰어에만 페이지 fragment를
   쓰고, 그 밖에는 원문 링크+페이지 번호+비파괴 강조 사본/페이지 이미지를 제공한다.
6. 정확한 문구를 찾지 못하면 강조 좌표를 추측하지 않는다. 원본·사본 SHA-256을 기록한다.

## 결과

Telegram을 실제 보조 원소스로 사용할 수 있으면서 봇 update 소비와 채널 변경 위험을 피한다.
페이지 직접 이동이 지원되지 않는 문서도 근거 위치를 즉시 확인할 수 있고 원본은 보존된다.
최초 사용자 인증이 없으면 수집기는 `not_configured`·`session_missing`·`unauthorized`를
명시하며 공개 원문 조사로 보고서를 완성한다.
