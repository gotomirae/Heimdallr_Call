# ADR 16 — 최신 투자기회는 점수 합산이 아니라 적응형 사전식 정렬로 찾는다

- 상태: 채택
- 날짜: 2026-09-11
- 관련: ADR 5, PRD §4.4·§9·§10

## 결정

발굴 목록의 기본 정렬은 최신 분기, 최종 등급, 최신 데이터의 섹터 기회 순위,
투자 매력도(기업·산업), 낮은 PRI, 영업이익 YoY 순으로 사전식 비교한다.
섹터 기회 순위 역시 ★/○ 비율, PRI 미반영 비율, 중앙 투자 매력도, 양(+)의
영업이익 성장 비율을 순서대로 비교하며 산술 합산하지 않는다.

공식 매크로는 한국은행 RSS의 최근 관련 원문 제목과 링크를 표시해 금리·산업·지정학
점검 조건을 알린다. 뉴스의 언급 횟수나 감성은 선택 점수로 만들지 않는다. 실제 섹터
우선순위는 매 갱신된 실적·가격이 확인한 결과로만 바뀐다.

## 이유

현재 투자기회를 찾겠다고 기업 점수와 `100-PRI`, 뉴스 빈도를 한 숫자로 합치면
펀더멘털·가격·사건의 서로 다른 의미가 사라진다. 반면 사전식 정렬은 왜 위에 있는지
설명 가능하고, ADR 5의 두 축을 보존하면서 최신 시세와 실적에 매번 반응한다.

## 결과

- 기본 정렬은 좋은 기업보다 현재 등급과 미반영 기회를 먼저 보여 준다.
- 외부 원문 장애 때도 실적·가격 정렬은 독립적으로 계속 작동한다.
- 사용자가 머리글을 누르면 기존 다중 정렬이 우선하며 언제든 `기본`으로 돌아간다.
