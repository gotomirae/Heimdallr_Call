# ADR 36: 분기 단독 신규수주와 공식 IR 수주 근거

PRD Ref: §9.1-3 · 2026-10-08

- 분기 신규수주 막대는 당분기 직접 공시 또는 같은 회계연도·통화·범위·결산월의 직전 누적액 차감으로 만든다. Q1은 누적액이 단독액이다. 누적 원자료는 별도 열에 보존하며 이전 비교 원문 없음·음수 차액·기간 불명은 결측과 이유로 표시한다.
- 회사 공식 IR의 명시 분기·단위·범위를 확인한 수주표를 DART 발췌에 별도 키로 저장한다. IR 숫자를 DART 숫자로 표시하거나 다른 사업 범위의 신규수주와 잔고를 섞지 않는다. 실제 PDF 원문·페이지·SHA256를 보존하고 DART 재수집이 IR 키를 지우지 않는다.
- 그림/벡터 표는 직접 렌더링하여 대조한 검증 장부와 원문 해시가 일치할 때만 받아들인다. 연간 목표·예상 수주·환율 추정·수주총액에서 임의 역산한 신규수주는 사용하지 않는다.
- 표에 명시된 기준일이 실제 분기말과 다르면 분기 차트에서 제외한다. 기존 잘못된 값은 원문과 함께 별도 비분기말 근거로 보존한다. 일부 비공개 표의 공개 항목은 항목 범위로 남기며 회사 합계를 만들지 않는다.

## 실측과 한계

정기보고서 11,866건 조회 결과 수주 지표 372기업, 잔고 3,786점, 같은 범위 연속 분기 QoQ 3,007점/353기업. 신규수주 원자료 150점/16기업 중 실제 최근 10분기 단독 변환은 132점/14기업이다. 공식 IR 3기업 18분기 저장 재조회 완료. 전체 수주 기업의 세 지표를 모두 확보했다는 선언은 아직 할 수 없다. 신규수주 미확보를 일괄 비공개로 판단하지 않는다.
