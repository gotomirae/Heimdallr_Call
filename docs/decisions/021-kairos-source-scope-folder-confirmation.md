# ADR 21. Kairos 최신 자료 범위와 Drive 산업 폴더 확인

- 상태: 채택 (2026-09-26)
- PRD: §8.7

## 문제

산업 Drive 루트의 폴더명은 순서 숫자, 공백, 별칭, 더 넓은 범위를 포함한다.
요청어와 비슷하다는 이유로 자동 선택하면 다른 산업을 정상적으로 분석하는 조용한 오류가 생긴다.
또한 산업·기업 Drive에 동일한 `최신 폴더 하나` 규칙을 적용하면 기업의 최근 3개월 보고서를
누락할 수 있다.

## 결정

1. 산업 Drive는 확정된 산업 폴더의 가장 최근 날짜 하위 폴더 하나만 사용한다.
2. 산업 분석 후 본문에 실제로 비교·추천하는 기업과 기업 직접 요청은 기업 Drive의
   해당 기업 폴더에서 최근 3개월 이내 발행 자료 전체를 사용한다.
3. 폴더 비교에서 숫자 접두어·공백·밑줄·하이픈만 제거한다. 정규화 후에도 다르면
   `working → awaiting_input`으로 멈추고 Telegram 확인 메시지의 `예/아니오` 답장을 받는다.
4. `예`는 같은 요청 ID·체크포인트를 `working`으로 재개한다. `아니오`는 `rejected`로 종료하고
   다른 폴더로 자동 전환하지 않는다. 확인 메시지 ID에 직접 답장한 경우만 수락한다.
5. Notion SnowBall Heritage와 기업·산업 결과 부모는 모두 참고 탐색 루트로 사용한다.
   기업 요청은 동일 기업과 관련 산업, 산업 요청은 동일 산업과 실제 분석할 기업을 조회한다.
   본문에 날짜가 명시된 최근 3개월 자료만 현재 판단에 쓰고 오래된 직전 완성본은 변화 비교용으로만 쓴다.
   작성 중·실패·이번 실행 페이지는 제외하고, 모든 현재 사실과 수치는 Drive·공시·IR·웹 원문으로 재검증한다.
6. 웹 자료는 최근 3개월 1차 원문을 우선하고, 구자료는 구조적 배경·역사 비교에 필요할 때만
   발행일·한계를 표시해 사용한다.
7. Drive·Notion에서 발견한 토큰·키·비밀번호·자격증명은 분석 근거에서 제외하고
   값을 출력·원고·로그·프롬프트에 복사하지 않는다.

## 결과

- 폴더 승인이 필요한 요청은 사용자 답장 전에 Notion을 작성하지 않는다.
- 확인 상태·후보·메시지 ID·응답·시각은 Supabase와 로컬 SQLite에 영속한다.
- 운영 적용에는 `docs/migrations/kairos_drive_confirmation.sql`이 필수다.
