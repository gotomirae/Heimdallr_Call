# ADR 38: 수주기업 분류를 금액 확보 여부와 분리한다

상태: 채택 · 2026-10-08 · PRD §9.1-3

시총 하한을 넘는 전체 기업을 대상으로 수주 확인·비수주 명시·확인 필요의 세 상태를 기록한다. 수치 파싱 성공 기업만을 분모로 삼지 않는다. 정기보고서 전체 수주표, 직접 잔고 문구, 영업비밀·보안 비공개 문구, 실제 공급계약 공시가 수주 근거다. 단순 기재 생략·자료 부족·수주 절 존재만으로 확정하지 않는다. 최신 비수주 문구와 과거 수주 증거가 충돌하면 확인 필요로 남긴다.

각 기업의 최신 정기보고서 기간과 같은 범위·통화에서 잔고·분기 신규·QoQ가 모두 측정된 경우만 최신 세 항목 확보로 센다. 과거 완전 자료, 회사 전체와 부분 사업, 누적 신규와 분기 신규, 공개 계약 하한은 서로 바꾸지 않는다. 부분 범위를 포함한 회사 수라는 사실을 화면에 명시한다.

분류 원문과 금액 원문은 각각 연결한다. KIND IR 후보 발견·파일 읽기와 수치 승인도 분리한다. 후보 미검출·파일 미등록은 비수주나 회사 미공개 판정이 아니다. 미확보 이유와 조사 파일 수를 공개하고 회사 자료실 추가 조사 대상으로 남긴다.

장부는 기존 공시 앵커의 독립 sections 키에 저장하고 공시 재수집 시 보존한다. 실제 공시 앵커가 없으면 가짜 공시 행을 만들지 않고 화면에서 확인 필요로 표시한다. 기존 종목코드 인덱스를 사용한 제한된 묶음 조회로 전체 JSON 테이블 스캔을 피하되 각 조회는 range 페이징을 유지한다. 정기 수집 뒤 같은 대시보드 순수 계산으로 장부를 갱신한다.
