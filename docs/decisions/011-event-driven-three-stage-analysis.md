# ADR 11 — LLM 분석은 세 정보 이벤트에만 연다

날짜: 2026-09-07

## 결정

자동 유료 LLM 분석은 성장 가속 종목 중 텔레그램 발송 등급 ★·○에만 적용한다. 한 분기는
잠정실적 발표, 분기·반기·사업보고서 공시, 정기보고서 뒤 실제 KOSPI 5거래일 리포트 창 종료의
세 단계로 관리한다.

3단계의 구체적인 자료원과 호출 조건은 같은 날의 사용자 후속 지시에 따라 ADR 13으로 개정됐다.
공시 뒤 실제 5번째 거래일이라는 시점과 종목당 한 번이라는 상한은 유지하되, 컨센서스 변화가
없어도 최근 10일 증권사 리포트를 공개 웹검색한다. 주가만으로 바뀌는 PER·선행 PER은 계속
재호출 증거에서 제외한다.
시세·시가총액·PRI는 매일 갱신하지만 유료 분석 근거에는 넣지 않는다.

자동 야간 따라잡기 스케줄은 제거하고 수동 장애 복구로만 남긴다. 기존 레거시 분석을 새 단계에
소급 편입하지 않는다.

## 이유

2026-09-07 야간 실행은 209종목 중 94건을 호출해 성공 1건, 실패 93건이었고 실패 응답에도
약 $6.49를 썼다. 전날도 성공 1건·실패 93건이었다. 변경 실패를 저장하지 않아 같은 근거가
다음 날 다시 유료 호출됐고, 메타 보강의 `updated_at`을 새 투자 정보로 오인해 과거 분석이
대량으로 다시 열렸다.

발굴과 산업 비교는 구조화 재무 기반 스크리너가 무료로 전수 수행한다. LLM의 추가 효용은
투자 알림을 받은 후보의 원인·지속성·리스크 해석에 집중된다. 따라서 모든 성장 가속 종목에
매일 해석을 붙이는 것보다 정보가 생기는 순간의 ★·○에만 쓰는 편이 목적과 비용에 맞다.

## 되돌리면 무엇이 무너지는가

야간 전수 배치나 시세 변화 기반 재분석을 되살리면 새 기업 정보가 없어도 과거 종목이 매일
유료 큐에 들어간다. 3차 호출을 5번째 거래일 뒤 종목당 한 번으로 제한하지 않으면 같은 검색과
본문을 반복 생성해 빠른 이벤트 해석 예산을 소모한다.
