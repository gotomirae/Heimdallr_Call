# ADR 18 — 미국 중심 글로벌 매크로와 상호작용 우선 갱신

- 상태: 채택
- 날짜: 2026-09-12
- 관련: ADR 5, ADR 13, ADR 16, PRD §7·§9·§10

## 결정

발굴 목록의 거시 맥락은 한국 국내 자료보다 미 연준·BLS·BEA·IMF 공식 자료를 중심으로
작성한다. 미국 AI·데이터센터 설비투자와 연결된 반도체·전력 공급망을 기본 섹터 기회로
앞세우되, 구조화 실적에서 ★/○가 확인된 섹터만 실제 정렬에서 승격한다. 고금리·물가·통상·
지정학 위험 때문에 투자 매력도, 낮은 PRI, 낮은 내년 F.PER, 높은 내년 F.ROE를 차례로 본다.

사용자 다중 정렬은 먼저 선택한 우선순위와 방향을 보존한 채 새 열을 다음 규칙으로 추가한다.
같은 머리글은 내림·오름만 토글하고, 제거는 개별 × 또는 기본 복원으로 명시한다.

공식 매크로 외부 호출은 대시보드 페이지 렌더 경로에서 분리한다. 자동 전체 갱신은 최근
클릭·입력·스크롤 중에는 보류하고, 종목 링크의 대량 프리패치를 끈다. 목록 쿼리는 화면에
필요한 열만 읽으며 일시적 연결 실패에는 상태 보존형 재시도 UI를 제공한다.

3단계 LLM은 지정 텔레그램 공개 채널 두 곳과 일반 웹검색에 더해, 직전 4개 분기 DART
정기보고서의 최신 정정본 제한 발췌를 1차 출처로 받는다. 내러티브 판단은 당시 주장과 이번
분기 매출·영업이익·OPM을 대조하고, 검색 결과 URL 또는 접수번호 검증 DART 링크만 저장한다.

## 이유

한국 종목의 가격과 수출 이익 경로는 미국 금리·수요·AI 자본지출과 글로벌 에너지·통상 충격의
영향을 크게 받는다. 동시에 외부 공식 사이트나 수백 개 상세 링크의 요청이 화면 렌더와 겹치면
정확한 데이터가 있어도 사용자는 연결 끊김과 클릭 무응답으로 경험한다. 매크로 판단, DB 최신성,
사용자 상호작용을 서로 다른 경계로 분리해야 세 가지를 함께 지킬 수 있다.
