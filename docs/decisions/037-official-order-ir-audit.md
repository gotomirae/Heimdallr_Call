# ADR 37: 수주 IR 출처 조사와 수치 승인을 분리한다

상태: 채택 · 2026-10-08 · PRD §9.1-3

KIND 공식 제출 IR은 POST 페이징으로 날짜·회사코드·실제 파일을 확인하고, 원문 URL·해시·후보 페이지·텍스트 없는 페이지를 조사 장부에 보존한다. 후보 미검출·자료 미등록은 회사의 수주 미공개 판정이 아니다. 회사 공식 자료실을 별도로 보완한다.

표의 실제 기준일·신규수주 기간·단위·사업범위를 직접 대조한 수치만 검증 장부로 승인한다. 연간 목표·예상치·월중 누적치를 분기 실적으로 넣지 않는다. 삼성중공업의 인도 기준 외화 잔고는 매출 기준 원화 잔고와 분리한다. 신규수주 누적액은 같은 범위의 직전 분기 원문이 있을 때만 분기 단독액으로 변환한다.

같은 보고서의 IR 여러 사업부는 최신 sections를 읽어 해당 범위만 대체하고 다른 사업부와 근거를 보존한다. 회사·분기별 세 항목 확보 여부를 공개된 실제 수치로 집계하고 미확보는 후속 조사 장부에 남긴다. 자료의 존재만으로 모든 회사의 세 항목 확보 완료를 선언하지 않는다.

공식 폼 전용 다운로드는 회사·자료실·파일 ID를 고정 검증하고 공개 CSRF 절차로 내려받는다. 원문 해시와 페이지를 저장하되 사용자 출처 링크는 실제 자료실로 연결한다. HTML URL에 PDF 페이지 fragment를 붙이지 않는다. 잔고가 재표시되거나 반올림 정밀도가 명시적으로 달라진 계열은 별도 범위로 보존한다.

검증 장부의 금액은 Decimal 고정 소수점으로 직렬화한다. :g의 기본 6자리 반올림·지수 표기를 DB 지표 계약에 사용하지 않는다. 원문 값→저장 문자열→실제 대시보드 파서 회귀로 손실 없는 전달을 확인한다.
