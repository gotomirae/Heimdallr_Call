# ADR 32 — Telegram 리서치 소스 제외

2026-10-07 사용자 결정: Telegram 리서치를 분석 소스에서 제외한다.

Codex Kairos·Claude 심층 분석/발표자료·Heimdallr LLM 리포트 검색에서 Telegram 채널·게시물·첨부·재배포 링크를 사용하지 않는다. 과거 체크포인트·sources의 해당 자료도 새 분석 근거에서 제외한다. 필요한 보고서는 공시·IR·증권사 등 원 발행기관에서 직접 확보한다.

Telegram 연구 채널과 리포트 우선 채널 설정을 빈 목록으로 고정한다. 연구 status/search/auth는 자격증명 조회·네트워크 연결 전에 disabled로 종료한다. 기존 수집 유틸리티·역사 장부는 보존한다. 봇의 실제 사용자 요청 수신·진행 상태·완료 알림은 별도의 전달 경로로 유지한다.

자료 근거는 Google Drive·Notion·공시·IR·증권사 공식 자료·공공 통계·웹 원문을 사용한다. 연구 세션 인증은 더 이상 사용자 할 일이 아니다.
