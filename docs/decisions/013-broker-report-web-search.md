# ADR 13 — 3단계는 최근 10일 증권사 리포트를 공개 웹검색한다

날짜: 2026-09-07

## 결정

정기보고서 공시 뒤 실제 KOSPI 5번째 거래일에 성장 가속 ★·○ 종목을 한 번 최종 갱신한다.
이 호출에만 웹검색을 켜고, 공시일 이후이면서 종료일 기준 최근 10달력일 안에 발행된 증권사
리포트를 찾는다. `선진짱 주식공부방`과 `소중한추억.`을 먼저 검색하고 부족할 때만 일반 웹으로
보완한다. 한 종목당 검색은 최대 3회다.

발행 증권사·리포트명·발행일·직접 URL이 실제 Provider 검색 결과에서 확인된 항목만 payload에
남긴다. 텔레그램은 발견 경로이며, 연결된 증권사 원문이 있으면 원문과 DART 공시를 우선한다.
컨센서스 변화가 없어도 이 최종 검색은 한 번 수행한다. 1·2단계와 매일 시세 갱신에는 검색을
켜지 않는다. 서버 웹검색 횟수는 usage에서 읽어 건당 공식 검색비까지 `cost_log`에 합산한다.

## 이유

사용자의 최종 목적은 실적 성장 가속과 그 원인을 가장 빨리 투자 판단으로 연결하는 것이다.
컨센서스 수치만으로는 리포트에 새로 등장한 고객사·수주·실적 전망 변화의 맥락을 놓친다.
반대로 매일 검색하면 새 공시도 없이 비용과 중복 분석만 누적된다. 5번째 실제 거래일 한 번,
★·○만, 최대 3회 검색이면 자료가 모일 시간을 주면서 비용을 결정적으로 제한할 수 있다.

## 되돌리면 무엇이 무너지는가

지정 채널 우선순위나 발행일·URL 검증을 없애면 오래되거나 출처가 불명확한 요약이 최신 리포트로
표시된다. 3단계 밖에서 검색을 켜거나 매일 재검색하면 시세 변화만으로도 유료 호출이 반복된다.
검색 횟수를 비용에서 빼면 월 실링이 실제 지출보다 낮게 보여 비용 방어선이 조용히 틀린다.
