# ADR 12 — 미근거 사실 숫자는 토큰만 제거하고 정성 해석은 보존한다

날짜: 2026-09-07

## 결정

운영 LLM 응답의 과거·현재 사실 필드에 입력으로 검증할 수 없는 숫자가 있으면 해당 숫자
토큰만 `[검증 불가 수치 삭제]`로 치환한다. 치환 뒤 동일한 결정론 검사를 다시 통과해야만
저장한다. 삭제 목록은 `_heimdallr.removed_factual_numbers`에 남기고 화면에 알린다.

구조가 깨졌거나 출력 상한으로 잘린 응답처럼 안전하게 복구할 수 없는 실패는 저장하지 않되,
`(분석 단계, 근거 hash)` 실패 기록을 남겨 같은 근거로 자동 재호출하지 않는다. 새 정보가
들어와 단계나 hash가 바뀌면 다시 열리며, 명시적 수동 복구는 가능하다.

## 이유

2026-09-07 배치 실패 93건 중 90건이 입력에 없는 사실 숫자 하나 이상 때문이었다. 이미
결제한 응답 전체를 버리고 같은 입력으로 다음 날 다시 요청해도 모델의 숫자 복사 순응이
개선된다는 보장이 없다. 정량 재무·주가 값은 대시보드가 결정론적으로 별도 표시하므로,
검증되지 않은 숫자를 제거한 정성 해석은 투자 검토에 남길 가치가 있다.

## 되돌리면 무엇이 무너지는가

응답 전체 거부로 돌아가면 단일 숫자 오류 때문에 원인·전망·리스크 해석까지 폐기되고 같은
입력을 반복 결제한다. 반대로 검증 없이 숫자를 저장하면 그럴듯한 허위 수치가 화면과 알림을
오염시킨다. 토큰 단위 제거와 재검사는 두 위험을 동시에 막는 경계다.
