# ADR045 · 공식 IR 목록별 첨부와 이미지 표의 근거 보존

공식 IR의 국문·영문 목록 갱신 시점이 다르면 한 목록만 조사해 최신 분기를 빠뜨린다. GS건설의 국문2026Q2를 공식 홈페이지 링크로 추가한다. 이미지 표는 텍스트 미검출을 미공개로 판단하지 않고 직접 렌더링·단위·분기·범위를 대조한 사실만 장부에 등록한다.

공개 자료실의 일회용 nonce는 저장하지 않는다. 코오롱글로벌에 한해 회사/호스트/게시판/양의 정수 게시물ID가 맞는 공개 목록에서 매번 새 링크를 얻는다. 목록 항목이 없거나 중복·해시 변경이면 자동 추측 대신 재검증 오류를 낸다. 자료실 주소가 같은 두 게시물의 다운로드 캐시는 게시물ID로 구분한다. 화면에는 자료실 링크를 쓰고 PDF 페이지 링크를 가장하지 않는다.

삼성물산 건설·레저 GSS 합계는 독립 범위로 보존한다. 코오롱 IR 신규와 DART 잔고는 동일 사업범위가 확인되기 전까지 합치지 않는다. 신규만 확보했어도 그대로 그래프에 반영하며 기말잔고와 QoQ를0이나 역산치로 채우지 않는다.
