# ADR 28 — 실적 시즌 전략 원본과 검증 장부

날짜: 2026-10-05

결과 추적에 1·4·7·10월 전략을 추가한다. 현재 화면의 회고를 다시 계산하는 것만으로는
발표 전에 어떤 종목을 선택했는지 검증할 수 없으므로, 최초 수립일의 판단을 불변 스냅샷으로
보존하고 검증 필드만 매일 갱신한다. 과거 전략을 소급 생성하지 않는다.

기존 매크로처럼 GitHub Actions가 공개 금융 자료를 저장한 JSON 장부를 커밋한다.
추가 DB DDL·공개 쓰기 API·유료 모델 없이 동작하며 원본 변경은 Git 이력으로 추적한다.
가격은 네이버 확정 일봉, 실적·분석·컨센서스·공시는 Heimdallr 전용 DB에서 읽는다.

수립 다음 첫 거래일 종가 이후의 고정 후보 성과를 소속 지수와 동일 날짜로 대조한다.
거래일은 지수 달력으로 세며 거래정지 종목을 조용히 제외/교체하지 않는다. 중앙값과
측정수는 후보 관찰값으로 표시하고 실제 매매 수익률이나 최적 매수 시점으로 주장하지 않는다.

부진 피드백은 각 시즌 최소 표본이 있는 두 시즌 이상에서 알려진 D+60만 사용한다.
변경은 다음 전략의 섹터 재확인 우선순위에만 적용한다. 스크리너 배점·PRI·게이트를
바꾸지 않고, 원 전략 후보를 바꿔 과거 성과를 개선하지 않는다.
