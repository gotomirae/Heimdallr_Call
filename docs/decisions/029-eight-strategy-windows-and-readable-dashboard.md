# ADR 29 — 연8회 사전 추천과 흰색 본문

2026-10-05 사용자 후속 지시에 따라 ADR28의 1·4·7·10월 단건 생성을
1·2·4·5·7·8·10·11월 첫째 주(한국시간1~7일)의 연8회로 확대한다.
첫째 주 밖에서는 새 전략을 소급 생성하지 않고 기존 사후 검증을 갱신한다.

저장된 이전 season-v1을 변경하지 않고 season-v2/w1 장부를 별도로 만든다.
예상 실적 가속·전망 상향·날짜 있는6개월 촉매·외국인/기관 연속 매수의 원자료를 각각
표시한다. 전부 충족한 후보만 우선 검토이며, 부족한 근거를 가진 후보는 조건부 추천이다.
추가 유료 모델 없이 현재 공개 원천과 유효 저장 분석을 활용한다. 같은 분기의 여러
추천을 서로 다른 실적 시즌으로 세지 않으며 미래 수익률로 원본을 다시 선택하지 않는다.

본문은 흰색, 핵심은 의미별 색을 쓴다. 회색 글자를 없애고 긴 설명은 문장 단위로
나누어 이모지와 줄바꿈을 붙인다. 표의 가로 스크롤을 유지하면서 페이지 스크롤에도
머리글을 보이기 위해 실제 열 너비와 가로 위치를 따르는 고정 머리글을 사용한다.
기존 정렬 제어의 클릭은 원본으로 전달하며 별도 키보드/접근성 항목을 중복 노출하지 않는다.
