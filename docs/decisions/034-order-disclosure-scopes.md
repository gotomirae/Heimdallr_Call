# ADR 34: 수주표의 공시 범위와 통화를 분리하여 보존한다

2026-10-08 · PRD §9.1 · 사용자 수주잔고/신규수주/QoQ 복구 요청

수주표 하나를 회사 전체 합계 한 값으로만 승인하면 여러 사업부·종속회사를 공시한 기업의 값이 모두 사라진다. `공시 수주지표 목록.series`에 원문의 각 범위별 구조화 문자열을 보존한다. 기존 `공시 수주지표`는 단일 범위 또는 회사 합계와 주요계약 부분집합 중 유일한 대표 범위가 있을 때만 유지한다. 종목 상세는 범위·통화마다 별도 그래프를 만든다.

원문 표의 명시 합계·단일 현재 행을 우선한다. 합계가 없는 표는 모든 독립 항목의 금액이 명시되어 있고 항목명이 유일하며 중복 소계·총계가 없는 경우에 한해 같은 표 안에서 합산하고 `공시 항목 합산(표 범위)`로 표시한다. 누락·비공개·단위 미확인 항목을 0으로 보충하지 않는다. 여러 표나 연결회사를 합산하지 않는다. 상세표 참조는 같은 보고서의 해당 상세 절을 함께 읽는다.

외화 수주잔고는 원문의 USD/RMB/IDR를 유지한다. 단위 크기만 백만 단위로 통일하고 임의 환율로 원화 잔고에 섞지 않는다. 최소구매물량의 확정 계약 잔고와 예상 구매 시나리오를 구분한다. QoQ는 같은 범위·통화·결산월의 바로 인접한 분기끼리만 계산한다.

신규수주는 명시 당기/신규수주 열이나 원문 각주가 당기 수주로 정의한 값만 승인한다. 수주총액·기초이월·기납품액으로 임의 역산하지 않는다. 보고기간 누적과 당분기를 구분한다. 파서 표식은 v6이며 기존 발췌의 다른 항목을 보존하여 재검증한다. 조회 장애는 빈 배열 대신 재시도 후 화면의 부가 데이터 경고로 전달한다.
