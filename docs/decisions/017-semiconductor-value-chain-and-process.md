# ADR 17 — 반도체는 사업 역할 6분류와 공정 표식을 분리한다

- 상태: 채택
- 날짜: 2026-09-12
- 관련: PRD §9, ADR 16, traps T152·T154·T155

## 결정

반도체 투자 섹터는 `IDM`, `DSP`, `OSAT`, `소재`, `부품`, `장비`의 여섯 역할로
분류한다. 분류는 회사명 목록이 아니라 KRX 업종·주요제품의 일반 증거어로 판정한다.

공정 위치는 섹터명과 별도 속성으로 계산한다. 소재·부품·장비는 제품 증거가 있을 때만
전공정 `전` 또는 후공정 `후`를 작은 표식으로 표시한다. OSAT는 정의상 `후`로 표시한다.
IDM은 전·후공정을 함께 수행할 수 있고 DSP는 설계 단계이므로 공정 표식을 붙이지 않는다.
근거가 부족하면 추정하지 않고 `None`으로 남긴다.

## 이유

IDM·설계·외주 패키징은 이익을 움직이는 요인이 다르고, 같은 장비·소재 안에서도 전공정과
후공정의 투자 사이클이 다르다. 이를 한 `반도체` 섹터로 묶으면 산업·피어 점수의 분모가
서로 다른 사업을 섞는다. 반대로 공정 위치를 섹터명 자체에 넣으면 필터와 시계열 집계가
쪼개지므로 화면 표식으로만 병기한다.

## 결과

- Python 저장 분류와 TypeScript 읽기 분류·공정 표식을 같은 생성 상수로 동기화한다.
- `반도체 테스트 서비스`는 OSAT, `테스트 핸들러`는 장비, `테스트 소켓`은 부품으로 구분한다.
- `웨이퍼 테스터`는 웨이퍼라는 단어가 있어도 후공정 테스트 예외가 우선한다.
- 개별 종목 하드코딩을 하지 않아 신규 상장사도 같은 사업 증거 규칙으로 분류된다.
