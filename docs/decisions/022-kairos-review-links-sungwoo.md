# ADR 22. Kairos 확인 필요 자료·종목 링크·SungwooInsight 범위

- 상태: 채택 (2026-09-26)
- PRD: §8.7

## 문제

웹 검색에서 제목이나 미리보기만 보이고 본문·이미지·영상은 읽히지 않는 자료를 조용히 제외하면
사용자가 직접 확인할 중요한 단서를 잃는다. 반대로 읽지 못한 내용을 사실로 요약하면 근거가
없는 판단이 된다. Peer 표와 본문 종목도 이름만 있으면 사용자가 다시 검색해야 한다.

## 결정

1. 분석과 관련성이 있으나 내용을 충분히 파악하지 못한 블로그·뉴스·Telegram 자료는
   `⚠️ 직접 확인 필요` 표에 제목·작성자·시각·사유·예상 관련성·직접 링크를 남긴다.
2. 확인 필요 자료는 사실·수치·투자 판단의 근거로 사용하지 않는다.
3. Peer 표와 최종 보고서에 등장하는 상장사는 정식명·티커·시장으로 식별하고 종목명에
   네이버증권 상세 직접 링크를 건다. 국내 종목은 검증된 6자리 코드만 사용한다.
4. 기업·산업 모든 분석은 `t.me/SungwooInsight`의 분석일시 기준 직전 72시간 게시물을
   반드시 확인한다. 관련 게시물은 시각·관점·직접 링크와 함께 싣고 핵심 수치는 공식 원문으로
   교차 검증한다.
5. 최근 72시간 관련 글이 없거나 채널 본문을 열 수 없으면 그 사실을 명시하고 채널 또는
   확인 가능한 게시물 링크를 제공한다. 오래된 글로 대체하거나 완료를 무기한 막지 않는다.

## 결과

- 사용자는 자동 해석이 불가능한 자료를 보고서에서 직접 열어 후속 판단할 수 있다.
- 종목명에서 네이버증권으로 바로 이동할 수 있고, 잘못된 코드 추측은 막는다.
- 사용자의 최근 Telegram 관점은 매 보고서에서 동일한 72시간 기준으로 확인된다.
